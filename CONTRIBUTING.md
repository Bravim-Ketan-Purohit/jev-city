# Contributing

Thanks for looking, but this repo is closed to contributions.

It is a finished experiment, published so people can read the code, run it and check the numbers. It is not under active development, so issues and pull requests are turned off, and pull requests opened from forks are closed automatically.

The MIT license still applies. You are free to fork it, change it and build your own thing with it. Please do.

If you spot something genuinely wrong, or you want to tell me how it went when you ran it, my contact details are on my GitHub profile.
